To fix it:

  1. Turn the frame off and take out the SD card.
  2. Put the card in a computer and open the drive called "bootfs".
  3. Create an empty file named memoryframe-reset (no extension).
  4. If there is a file named memoryframe-mode.txt, make sure it only says: product
  5. Put the card back and turn the frame on. Wait 1 minute.
